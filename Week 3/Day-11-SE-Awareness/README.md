<a name="overview"></a>

## 📌 Overview

Day 11 focuses on building a **Social Engineering Awareness Training Module** using Python.

The project implements an interactive command-line quiz containing scenario-based social-engineering questions. Users select answers, receive immediate feedback, and receive a final score after completing the quiz.

The module is designed to improve awareness of common social-engineering risks and safe security practices.

---

<a name="objective"></a>

## 🎯 Objective

The objective of this task is to design and develop an interactive **Social Engineering Awareness Quiz** in Python.

The quiz focuses on realistic scenarios, immediate feedback, and score tracking to demonstrate how security-awareness training can help users recognize social-engineering attempts.

---

<a name="key-concepts"></a>

## 🧠 Key Concepts

The training module covers important social-engineering awareness topics including:

- Phishing
- Vishing
- Smishing
- Suspicious links
- Suspicious attachments
- USB baiting
- Password security
- Multi-factor authentication
- Verification through official channels
- Social-engineering warning signs

Effective awareness training should use realistic scenarios, immediate feedback, and repetition.

<a name="how-to-run"></a>

## 🚀 How to Run

### 1. Open Command Prompt

Navigate to the Day 11 project folder:

```bash
cd C:\Users\AA\Desktop\Sqrock_Cybersecurity_Internship\Day-11-SE-Awareness
```

### 2. Run the Python Program

```bash
py awareness_quiz.py
```

### 3. Answer the Questions

The program displays a question with multiple-choice options:

```text
Q1: An email asks you to verify your password through a link.

A) Click the link
B) Contact IT through an official channel
C) Reply with your password

Your answer (A/B/C):
```

Enter:

```text
A
```

or:

```text
B
```

or:

```text
C
```

The program immediately tells you whether your answer is correct.

<a name="security-awareness"></a>

## 🛡️ Security Awareness

The quiz demonstrates several safe practices for reducing social-engineering risks:

* Verify suspicious requests through official channels.
* Do not provide passwords to callers or messages.
* Avoid clicking unexpected links.
* Verify unexpected attachments before opening them.
* Do not connect unknown USB devices.
* Use multi-factor authentication where available.
* Report suspicious activity to the appropriate security or IT team.
