## 📌 Overview

Day 6 focuses on **Spear Phishing Email Craft** for cybersecurity awareness training in an authorized laboratory environment.

The project uses Python to generate personalized phishing-awareness email templates using fictional target information. The purpose is to understand how personalization and social-engineering techniques can make phishing messages appear convincing and how users can identify the associated warning signs.

## 🎯 Objective

To build a Python-based email template generator that creates three personalized phishing-awareness training emails using fictional laboratory data.

## 🛠️ Tools & Technologies

- **Python 3.x**
- **Python Standard Library**
- **IDLE / Command Prompt**
- **GitHub**

## 📊 Output

The program generates **three personalized phishing-awareness email drafts** using fictional data.

The generated emails demonstrate common social-engineering indicators such as:

* Urgency
* Account suspension threats
* Unexpected login notifications
* Verification requests
* Suspicious links

A screenshot of the program output is included in the `screenshots` folder.

## 🛡️ Defensive Awareness

Organizations can reduce spear-phishing risks by implementing:

* **SPF** — Sender Policy Framework
* **DKIM** — DomainKeys Identified Mail
* **DMARC** — Domain-based Message Authentication, Reporting and Conformance
* Multi-factor authentication (MFA)
* Security-awareness training
* Verification of suspicious requests through official channels

## 🔐 Ethical & Legal Notice

This project is strictly intended for **authorized cybersecurity awareness training and laboratory environments**.

* No real phishing emails were sent.
* No real users were targeted.
* Fictional target information was used.
* The generated links are for laboratory awareness purposes.
* This project must not be used to conduct phishing attacks against real individuals or organizations.
